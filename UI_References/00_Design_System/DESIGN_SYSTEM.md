# ToolsApp Locked UI System

> Final product name/logo are intentionally deferred. Use `ToolsApp` only as a temporary development placeholder and keep brand text centralized so it can be replaced later.

## Locked visual direction
- Modern premium SaaS / utility-platform UI.
- Light-first interface with generous whitespace, soft borders, restrained shadows, rounded cards, and strong visual hierarchy.
- Every page must be adapted from its named reference image. Do not copy logos, product names, proprietary text, people, or unrelated business content from the references.
- Preserve the reference's composition, density, card geometry, alignment, information hierarchy, and interaction pattern while applying the common ToolsApp design system below.

## Locked color theme: Sunset Orange
- Primary: `#F97316`
- Primary hover/pressed: `#EA580C`
- Secondary orange: `#FB923C`
- Soft orange surface: `#FFF1E6`
- Warm highlight: `#FFEDD5`
- App background: `#F8FAFC`
- Surface/card: `#FFFFFF`
- Main text: `#0F172A`
- Secondary text: `#64748B`
- Border: `#E2E8F0`
- Success: `#22C55E`
- Warning: `#F59E0B`
- Error: `#EF4444`
- Primary gradient where needed: `linear-gradient(135deg, #F97316 0%, #FB923C 100%)`

Use orange as an accent, not as a full-page flood. Most of the UI stays neutral white/slate.

## Locked typography
- Headings: **Sora**
- Body/UI: **Inter**
- Hero: 56–64px desktop, responsive down to 36–42px mobile
- Page title: 36–44px desktop
- Section title: 24–30px
- Card title: 18–20px
- Body: 16px
- Small/body metadata: 14px
- Labels: 13–14px / medium
- Buttons: 14–16px / semibold

## Common component direction
- Radius: 12px controls, 16px cards, 20–24px major panels/modals.
- Borders: 1px `#E2E8F0`, subtle and consistent.
- Shadows: soft and low-opacity; avoid heavy floating shadows.
- Minimum interactive target: 44px.
- Focus style: visible orange focus ring with sufficient contrast.
- Icons: simple outline/duotone icon set; keep stroke weight consistent.
- Motion: 150–220ms for hover/focus/transitions; avoid excessive animation.

## Responsive breakpoints to verify
- 1440 desktop
- 1280 laptop
- 1024 small laptop/tablet landscape
- 768 tablet
- 390 mobile

## Accessibility baseline
- Semantic landmarks and heading order.
- Keyboard reachable interactions.
- Visible focus indicators.
- Form labels and helpful errors.
- WCAG AA contrast target.
- `prefers-reduced-motion` respected.
